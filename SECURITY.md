# Security Policy for hAnnounce

## Supported versions

| Version | Supported |
| --- | --- |
| development (main branch) | yes — actively developed |

hAnnounce has not published a stable release yet; no released versions are supported. The
table above will be updated as releases become available.

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Please use GitHub's private vulnerability reporting on this repository
(`Security` tab → `Report a vulnerability`), or contact the maintainer through
[hauch.dev](https://hauch.dev) if that is unavailable.

Include as much information as possible:

- A description of the vulnerability and its impact
- Steps or a proof of concept to reproduce it
- The affected branch or version

You can expect an initial response within 7 days. We ask you to give us reasonable time to
prepare a fix before any public disclosure is made. Reports will be credited in the release
notes if the reporter agrees.

## Scope

- Vulnerabilities in hAnnounce code, build configuration, and CI workflows.
- Out of scope: vulnerabilities in Minecraft itself, Paper/Spigot, Gradle, or third-party
  plugins — report those to the respective projects.
