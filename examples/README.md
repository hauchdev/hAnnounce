# Examples

This directory will hold **example configuration** for hAnnounce features as they are
implemented.

**There are no example files yet.** Because no announcement functionality, configuration
system, or integrations exist in the code yet, no examples are written here. Any example
published prematurely would describe behavior that does not exist.

When features are implemented, this directory is expected to contain copy-paste-ready
example sets for real features only, kept in sync with the implemented configuration
schema.
